# Rank-1 pure composition acceptance

The implementation is isolated at code commit `18df5d9b3186fc6f1f5afa1be024210fae5d0543`, tree `f75cd00757922ddf57b3812a3975e80adad34d54`, based on `8475984a9ce1e8dbc987a8cf409f0747583c4878`.

A quantified pure body may now compose a parameter read or required field projection through direct calls to statically selected quantified pure functions. Each call has one required parameter and one positional argument. The body still has one expression tail and cannot use a monomorphic or dynamic call. [`SPEC.md`](../../../../../docs/SPEC.md) records this rule.

The checker generalizes call substitutions with callable and body facts, then rejects call-only type or row binders. The verifier checks callee substitution keys in the callee scope and symbolic evidence in the caller scope. It checks substituted arguments and results against checked body facts. It also checks nested row-lacks requirements and charges cloned symbolic types against the materialization work budget. Ground calls keep their existing materialization path.

The native witness in [`rank1-inference.xsh`](../../../../../tests/xsh/rank1-inference.xsh) composes `identity(name_of(value))` through exported pure helpers. It exercises both import orders, independent `Int` and `Str` instantiations, and a missing-field error. The [baseline failure](raw/native/baseline-red.stdout) records unresolved type and row evidence. That initial fixture also lacked required module documentation. The checked fixture includes it.

## Layout and limits

`FullRowArgument` grows by four bytes, from 12 to 16 bytes, to store a caller row-tail binder. `FullStore::retained_bytes` counts row-argument capacity using `size_of::<FullRowArgument>()`. No separate counter was added. The code commit changes 13 files by 1,929 additions and 208 deletions. The native fixture adds 52 lines.

This slice adds composition for one-argument direct calls to quantified pure functions. It does not add generic callable values, generic proc bodies, runtime inference, or broader solver behavior. No performance or corpus result was measured.
